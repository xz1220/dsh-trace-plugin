# Codex DSH Trace

## Register

product

## Users

Codex users reviewing local agent execution alongside an ongoing conversation.

## Product Purpose

Inspect the complete recorded client request, tool inputs and outputs, and execution timing. The native Codex MCP App reads official rollout-trace bundles locally, using incremental metadata indexing and lazy detail reads. Earlier HTML design reviews remain under design/ and contain explicitly simulated data.

## Design Direction

Follow the DSH trajectory's timeline, event ledger, and record inspector. Fit the Codex side panel, with an expanded view for longer request context. Use restrained product typography, neutral surfaces, and semantic event colors. Avoid chat-bubble repetition and large metric cards.

## Design Principles

- Start with the execution sequence; reveal long content on selection.
- Distinguish reconstructed context from the incremental request actually sent.
- Show unknown and missing information explicitly.
- Preserve reading position during updates.
- Keep record inspection local and fast.

## Accessibility

Keyboard operable controls, visible focus, text labels alongside color, readable code, reduced motion, and responsive side-panel layouts.
