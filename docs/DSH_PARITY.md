1. 初次源码/界面：替换旧渲染器为真实上游组件，修正分组、请求定位和摘要。
2. 深浅色/窄侧栏：修复图标 sprite；全局折叠、键盘展开和折叠内容搜索通过。

4. 安装与边界：长历史、时间线、实时追加、缺失前序、取消、压缩、多代理、Unicode、错误重试和键盘控制通过。
5. 最终图片/控件与安装版复验：用户批准替代测试窗口后，使用 Ego TaskSpace 21 完成上述剩余操作。发现并修复公共中文文案缺失，以及单调时钟接近零时首轮目录扫描被缓存跳过的问题；0.2.7 安装版再次通过上下文、代码换行、助手图片/灯箱、360px 深色和 MCP Apps 握手检查。

拖动检查使用真实指针手势，并透明观察原版写入的 DownloadURL；Chromium 不向 DOM drop 读回这个类型。接收端读取对应 blob 并校验源字节。这是浏览器导出证据，未冒充原生操作系统拖动。

真实录制完整上下文为 81,919 字符；实际复制内容与后端 SHA-256 均为 `6f4c7f2bfb58f43a7e2f00f39acc2f6999b62f9d2980164ff3d2fc14154bd043`。

性能：重复扫描问题已修复。0.2.7 本机后端的 1 万事件首批投影为 19.602ms、首索引 123.498ms，无变化轮询额外日志读取 0。曾有一次浏览器预览测得 282.5ms 轨迹可用/272ms FCP；缓存可能已热，且属于较早构建。这些都不是原生侧栏耗时。

## 2026-11-13 再对照：仍有差异

使用同一份受控任务事实（2 次请求、1 次 run_code、5 个轨迹行），将 **0.2.7 安装版** 与固定版本的**未修改 TrajectoryView/Table/Timeline/Toolbar** 分别运行，在 1100×820 下点击对照。原版驱动只注入受控快照和状态，关闭 composer 留白。这是组件级对照，不是完整 DSH 应用或 Codex 原生宿主验收。

此前“只剩原生验收”的判断需要修正。93 个上游文件未改，只能证明组件复用，不能证明外层状态、元数据和宿主样式的接入完全一致。

| 编号 | 差异 | 证据与影响 |
|---|---|---|
| D01，应修复 | 切换时间线模式未清除选区 | 实际拖选后切换：DSH 选区消失，当前仍保留，旧范围会被按新坐标解释 |
| D02，应修复 | 工具的助手来源链接依赖查看顺序 | 冷开工具：当前 0 个“助手消息”链接，DSH 1 个；当前先查看助手再回工具，链接才变成 1 个。初始元数据遗漏调用 ID，详情加载后才补齐 |
| D03，应对齐 | 默认模式和偏好记忆不同 | DSH 新状态默认等宽，时间线/换行使用共享持久化 store；当前默认实际时长，切换录制后时长 false→true、换行 true→false。DSH 持久化由原始源码核实，未把驱动中的模拟 store 当作其运行证据 |
| D04，视觉差异 | 搜索框多一层焦点框 | 当前全局 CSS 给搜索 input 加 solid 2px/-2px 内描边；DSH input 为 outline-style:none，由外容器表示焦点 |

| G02，接入缺口 | 跟随语言切换 | DSH 注册 8 种语言；当前固定中文，宿主上下文仅映射主题。此项为源码检查 |
